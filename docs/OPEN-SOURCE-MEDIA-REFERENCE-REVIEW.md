# Open-source media and marketing references — triage

**Reviewed:** 2026-10-17. This is a repository-level review of metadata, README, root files, and license files where available through GitHub. It is **not** a source-line-by-line security or dependency audit. Duplicate links in the request are listed once. No third-party repository was copied wholesale into MarketingOS.

## What “free” means here

An open-source code license can allow you to run software without paying a software vendor; it does not make GPU hardware, electricity, storage, hosting, model downloads, bandwidth, maintenance, or every model checkpoint free. It also does not make a hosted API free. Some listed projects are unlicensed, research-only, non-commercial, or explicitly call paid providers. Do not deploy their code or weights commercially until the applicable software, model, and asset terms have been checked.

## What MarketingOS now provides locally

- **Local PNG social graphic:** browser canvas template with editable brand, headline, supporting copy, CTA, accent, and square/story/wide sizes. It requires no model/API and is **not** AI-generated image art.
- **Local WebM promo:** browser canvas/MediaRecorder creates a short, silent, animated four-scene text-card video, downloadable to the user's device. It requires no model/API and is **not** generated footage, narration, music, or an MP4 editor timeline.
- **Optional self-hosted AI image generation:** `src/lib/comfyui.ts` sends a standard checkpoint workflow to an operator-hosted ComfyUI server. The server and checkpoint are not bundled; if configured, local failure does not trigger a paid fallback. It has not been live-tested.
- **Optional self-hosted AI video clips:** the same adapter can submit an operator-provided ComfyUI API-format workflow for 3–10 second clips. It requires prompt/frame placeholders, a compatible video model and nodes, GPU resources, and a private ComfyUI endpoint. The app returns the file to the active session rather than persisting it; the path is mock-tested but not live-inference-tested, and a local failure never triggers a paid fallback.
- **Optional self-hosted speech:** a generic OpenAI-compatible TTS adapter supports `/v1/audio/speech` services. No TTS runtime/model is bundled or live-tested; generated audio is session-only, voice cloning/avatar generation is not included, and model voice rights/consent remain the operator's responsibility.
- **Text:** self-hosted Ollama remains the default text provider. OpenRouter/Z.AI are explicit hosted alternatives.
- **Hosted media:** Z.AI media remains opt-in, Mureka is optional and may charge, and LTX/LongCat/VideoClaw/LiveTalk are not included as model runtimes.

Thus the application has configurable local/no-API generation hooks, but it does **not** provide every feature in these repositories and cannot promise all models/voices or performance better than paid services. Production-ready AI video/voice still needs an operator-run, licensed model deployment, durable/private media storage, queueing, hardware benchmarks, consent controls, and end-to-end verification.
