**Snapshot date:** 2026-10-17  
**Deduplicated count:** 138 unique repositories  
**Coverage:** 135 repositories accessible; 3 returned GitHub API HTTP 403  
**Purpose:** Durable, link-level record of the expanded repository list. This is not a claim that every source file, nested package, model weight, asset, or issue history was audited.

## Review method and limits

- Repeated GitHub URLs were deduplicated by `owner/repository`; all 138 unique entries appear below.
- For the 135 accessible repositories, GitHub repository metadata, the default-branch README, and root listing were retrieved. The GitHub license endpoint returned a license file for 113. The table records the repository metadata SPDX value and whether a license file was available; `NOASSERTION`/unreported does **not** grant permission.
- This review is at **link/README/root-listing level**. It is not a file-by-file source, dependency, security, content, model-weight, trademark, or legal audit. A declared code license does not necessarily license model weights, datasets, media, logos, or external services.
- The three private/unavailable `engralaminn-collab` entries could not be checked. They remain open items; no code was copied from them.
- Disposition codes distinguish product relevance from reuse permission. “Implemented” means a native capability/pattern was implemented or adapted—not that an upstream repository was cloned. Related references can remain relevant even when no full integration is appropriate.

## Disposition codes

| Code | Meaning |
|---|---|
| **I** | Applicable pattern adapted into native MarketingOS code in this task; no upstream implementation copied. |
| **N** | A related/native capability was inspected; this is not a feature-parity claim and the external project was not cloned. |
| **D** | Relevant enough to assess, but a full integration was deferred due to runtime, provider/data rights, cost, security, hardware, or product-scope constraints. |
| **R** | Reference-only or different product/runtime; no code, assets, or data imported. |
| **L** | No reuse; license metadata/terms are unasserted, nonstandard, or require compatibility/attribution review. |
| **X** | GitHub returned 403; source and license review is pending access. |
